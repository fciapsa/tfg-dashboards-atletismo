# Visualización de datos en el ámbito del atletismo

Este repositorio pertenece al Trabajo de Fin de Grado del Grado en Ingeniería Informática de Flavius Abel Ciapsa (Universidad Complutense de Madrid, curso 2024-2025). Contiene el código fuente de dos aplicaciones y el cuestionario de evaluación de una de ellas.

### Directorios

- `Introducción al ABP`: Aplicación creada utilizando la biblioteca `flexdashboard` de R. En ella se combinan componentes gráficos típicos de los dashboards con textos explicativos que introducen al usuario al funcionamiento de un programa antidopaje.

- `Dashboard - Mejores resultados`: Aplicación compuesta por dos dashboards creados utilizando la biblioteca `shiny` de R. La temática de ambos son las mejores marcas (resultados) obtenidos por los atletas en cada temporada, incluyendo gran variedad de pruebas oficiales.

- `Cuestionario de evaluación`: Versión impresa del cuestionario de Google Forms y Excel/CSV con las respuestas anónimas y sin procesar de los participantes en las pruebas con usuarios de la aplicación `Introducción al ABP`.
